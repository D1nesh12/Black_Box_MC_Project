# System Requirements Specification

## Hardware Requirements
* **Microcontroller:** 8-bit PIC Microcontroller (e.g., PIC18F4580).
* **Display:** 16x2 Character LCD (CLCD).
* **Input:** 4x4 Matrix Keypad.
* **RTC:** DS1307 Real-Time Clock (I2C).
* **Memory:** 24C04 or similar external EEPROM (I2C).
* **Sensors:** Potentiometers/ADC for speed/throttle simulation.

## Software Requirements
* **Firmware:** Written in Embedded C.
* **Toolchain:** MPLAB X IDE, XC8 Compiler.
* **Validation:** Hardware-in-the-Loop (HIL) testing compatibility for system validation.
