# Automotive Black Box - Project Summary

## Overview
The Automotive Black Box (Event Data Recorder) is an embedded system designed to capture, log, and display critical vehicle parameters in real-time. Operating as a standalone unit, it ensures that crucial event data is securely preserved in non-volatile memory for subsequent analysis.

## Core Objectives
* **Data Logging:** Accurately timestamp and record dynamic vehicle metrics.
* **Data Retention:** Safely store logs in an external EEPROM to prevent data loss upon power failure.
* **User Interface:** Provide an intuitive dashboard via a Character LCD (CLCD) and Matrix Keypad.
* **Diagnostics & Retrieval:** Enable real-time monitoring and historical data extraction via UART.
